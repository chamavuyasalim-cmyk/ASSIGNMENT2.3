## 1. Aim

## 2. Requirements

- Visual Studio Code
- A web browser

## 3. Procedure

1. Open the previous `index.html` file in VS Code.
2. Divide the webpage into Header, About, Education, Skills, and Contact sections.
3. Use `div` elements to group related content.
4. Assign unique IDs to individual sections.
5. Use reusable classes to maintain consistent styling.
6. Add a custom `data-*` attribute to an HTML element.
7. Update the existing text and add new content.
8. Format the code with proper indentation and meaningful names.
9. Save the file and open it in a browser.
10. Take a screenshot showing the completed webpage.

## 4. HTML Attributes Used

| Attribute | Purpose                                     |
| --------- | ------------------------------------------- |
| `id`      | Uniquely identifies an element on the page. |
| `class`   | Groups elements for reusable CSS styling.   |
| `data-*`  | Stores custom data on an HTML element.      |

## 5. Result

Successfully updated the personal introduction webpage with a clean HTML structure, organized sections, reusable classes, unique IDs, a custom data attribute, and additional content.
